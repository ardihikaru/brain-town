    Integrations

    One card per connected platform. GitHub has one card per owner: an organization, or a personal account with one webhook per repo. A card turns amber when a repo is missing events and red after a rejected delivery.

    Consumers

    A consumer is a machine that reads what the town saw. It is not an integration: an integration sends events in, a consumer reads them out. Each one has its own scoped token and reads only what it asked for.

    Add a consumer

    The token is shown once, right after you create it. Hand it to the platform through your own secret channel — never in this page.

    Leave a field empty to match everything in that dimension. Owners and repositories are matched case-insensitively; a repository is the bare name, without the owner.

    Copy the token now

    It is not shown again. A rotation replaces it and the old one stops working at once.

    What a consumer sees

    The public stream hides a hidden product's real name and every title. A consumer that asked for that repository by name gets the real name — the event was already reduced when it was stored, and the source payload itself is never kept.
